# المحترف الأكاديمي (Academic Atelier) 🎓

نظام إدارة أكاديمي متطور مصمم خصيصاً للمعلمين والمربين لتسهيل متابعة أداء الطلاب، رصد الدرجات، وإدارة الحلقات الدراسية بكفاءة عالية.

## ✨ المميزات الرئيسية

*   **كشف الدرجات الذكي:** رصد درجات التلاوة والتجويد والحفظ (بتقسيم 4 خانات لكل مهارة) مع حساب تلقائي للمجموع.
*   **الحفظ التلقائي:** مزامنة فورية لكل تغيير تقوم به مع التخزين السحابي (Google Drive).
*   **نظام الاستئذان:** تتبع تواجد الطلاب في الفصل (حمام، وكيل، موجه) مع تمييز بصري في كشف الدرجات.
*   **إدارة الفصول:** إمكانية استيراد قوائم الأسماء، إنشاء فصول جديدة، وأرشفة البيانات القديمة.
*   **متابعة الحفظ:** سجل مخصص لمتابعة السور والآيات ومقدار الإنجاز اليومي لكل طالب.
*   **الواجبات والمشاركة:** نظام تحديد سريع (Checkbox) لرصد إنجاز الواجبات اليومية والمشاركة الصفية.
*   **تقارير أداء:** تحليلات بيانية لمستوى الطلاب والصفوف وتحديد الطلاب ذوي الأداء الضعيف للمتابعة.

## 🚀 التقنيات المستخدمة

*   **React 18 & Vite:** لضمان سرعة واستجابة واجهة المستخدم.
*   **Tailwind CSS:** لتصميم عصري ومرن يتناسب مع كافة الشاشات.
*   **Motion (Framer Motion):** لإضافة تأثيرات وانتقالات سلسة تجعل تجربة الاستخدام أكثر متعة.
*   **Lucide Icons:** مكتبة أيقونات متسقة ومعبرة.
*   **Storage API:** ربط مخصص مع Google Drive لضمان أمان البيانات وسهولة الوصول إليها من أي مكان.

## 📱 التوافقية

تم تصميم التطبيق ليعمل بكفاءة على:
1. أجهزة اللابتوب والكمبيوتر المكتبية (عرض واسع للكشوف).
2. الأجهزة اللوحية (iPad/Tablets).
3. الهواتف الذكية (قائمة جانبية منسدلة وتخطيط مرن).

## 🛡️ أمان البيانات

جميع البيانات تُحفظ محلياً في المتصفح وتُزامن تلقائياً مع حسابك الشخصي في Google Drive. لا يتم تخزين أية بيانات خاصة بالطلاب على خوادم خارجية، مما يضمن الخصوصية التامة.
